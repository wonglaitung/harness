# 港股 Alpha 事件捕获技能

捕捉港股市场的 alpha 事件：政策驱动、资金流向、投行评级、衍生品异动。

## 领域特点

港股具有"多源共振"特性：
- **南向资金**：港股通净流入，内地政策影响
- **北向/外资**：美联储利率、外资投行评级
- **衍生品**：牛熊证、期权重货区

## 判断标准

### ✅ 左侧信号（绝对优先）

| 事件类型 | 示例 | 传导逻辑 |
|---------|------|---------|
| 回购潮 | 腾讯/美团大额回购 | 历史上回购潮往往是见底信号 |
| 游戏版号获批 | 腾讯核心手游获批 | 基本面修复，估值重估 |
| 美联储降息预期 | 点阵图偏鸽 | 港元挂钩美元，流动性改善 |
| 内地政策松绑 | 互联网监管放松 | 外资回补中概仓位 |

### ✅ 右侧共振（市场确认）

| 事件类型 | 示例 | 传导逻辑 |
|---------|------|---------|
| 投行评级上调 | 高盛上调腾讯目标价 | 外资定价权，机构建仓 |
| 港股通大额流入 | 单日净流入 >50亿 | 南向资金抢筹 |
| 牛熊证重货区变动 | Call证未平仓量上升 | 散户情绪转向 |

### ❌ 噪音过滤

| 事件类型 | 原因 |
|---------|------|
| 日常小幅波动 | 无基本面变化 |
| 分析师例行评级 | 滞后指标 |
| 公司日常公告 | 无重大影响 |
| CEO采访言论 | 往往是PR |

### 🚫 反面信号（必须回避）

| 警告信号 | 含义 | 应对 |
|---------|------|------|
| 短期涨幅 > 30% 后出现"左侧信号" | 追高风险 | 等回调 20% 以上再入 |
| 港股通连续 3 天流出 | 南向资金离场 | 暂停入场，等反转 |
| 大V荐股同时出现信号 | 可能是诱多 | 提高警觉，减仓 30% |
| 恒指处于历史高位且信号出现 | 高位接盘风险 | 观望，不操作 |

## 禁止交易窗口

| 时间段 | 原因 | 风险说明 |
|--------|------|---------|
| 美联储议息会前 3 天 | 不确定性最高 | 政策不确定导致剧烈波动 |
| 港股年报季（3月、8月）| 业绩地雷频繁 | 雷区密集，胜率下降 |
| 中国经济数据发布日 | 黑天鹅概率高 | GDP/CPI 超预期易触发止损 |
| 美股开盘 1 小时内 | 跟风风险 | 港股跟风美股，容易被套 |
| 恒指 VIX > 40 | 极度恐慌 | 系统性风险过大 |

**配置**：Agent 在这些时间段直接跳过操作建议，改为"观望"。

## 衍生品机会识别

### 牛熊证套利

- **发现指标**：Call证未平仓量突增 30%+ → 散户看多
- **操作**：直接买正股而非Call证（避免时间衰减）
- **风险**：若是庄家建空，Call未平仓增加反而是诱多

### 期权重货区

- **关键位**：每周期权行权价聚集区
- **操作**：在重货区上方/下方设置止损（概率大）
- **数据源**：港交所期权持仓数据（需接入）

## 工作流程

### 第一步：左侧信号扫描

1. 使用 `fetch_hkex` 获取回购/减持公告
   - 重点关注：腾讯(00700)、美团(03690)、阿里(09988)、小米(01810)
   - 回购金额 > 1亿港元 为重大信号

2. 使用 `fetch_financial_news` 获取政策快讯
   - 关键词：港股、美联储、监管、版号、回购、降息
   - 来源：财联社（国内政策）、华尔街见闻（全球宏观）

### 第二步：决策树过滤

```
发现左侧信号
  ├─ 是否为"回购潮"？
  │   ├─ 是 → 看多，入场等待右侧确认
  │   └─ 否 → 继续下一步
  ├─ 是否为"政策事件"？
  │   ├─ 是 → 查证权威来源，排除虚假信息
  │   └─ 否 → 继续
  ├─ 是否符合"禁止交易时间段"？
  │   ├─ 是 → 观望，记录到跟踪清单
  │   └─ 否 → 生成交易快报
```

### 第三步：传导逻辑推演

对发现的事件，分析影响路径：
- 基本面影响：对业绩/估值的影响
- 走势共振：南向/外资的反应
- 宏观环境：美联储、国内政策的配合

### 第四步：生成交易快报

使用 `save_one_pager` 的 **Simple 模式** 保存报告：

```
title: "{股票代码} - {事件关键词}"
content: "{完整的 Markdown 报告内容}"
domain: "stocks"
```

**⚠️ 重要**：必须使用 Simple 模式（title + content），不要用结构化字段（concept_name 等），因为港股报告需要完全自定义格式。

## 注意事项

1. **时效性优先**：港股对政策敏感，尽快完成判断
2. **区分左右侧**：左侧是机会，右侧是确认
3. **关注外资定价权**：投行评级对港股影响大
4. **噪音过滤严格**：99%的新闻是噪音，只推送重大事件
5. **使用 Simple 模式**：必须用 title + content 保存，不要用结构化字段
6. **量化优先**：估值、仓位、止损位尽量给出具体数值
7. **禁止交易窗口**：遇到禁止交易时间段，输出"观望"而非操作建议
