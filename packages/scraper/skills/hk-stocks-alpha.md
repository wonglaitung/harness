# 港股 Alpha 事件捕获技能

捕捉港股市场的 alpha 事件：政策驱动、资金流向、投行评级、衍生品异动。

## 领域特点

港股具有"多源共振"特性：
- **南向资金**：港股通净流入，内地政策影响
- **北向/外资**：美联储利率、外资投行评级
- **衍生品**：牛熊证、期权重货区

## 判断标准

### ✅ 左侧信号（绝对优先）

| 事件类型 | 示例 | 传导逻辑 |
|---------|------|---------|
| 回购潮 | 腾讯/美团大额回购 | 历史上回购潮往往是见底信号 |
| 游戏版号获批 | 腾讯核心手游获批 | 基本面修复，估值重估 |
| 美联储降息预期 | 点阵图偏鸽 | 港元挂钩美元，流动性改善 |
| 内地政策松绑 | 互联网监管放松 | 外资回补中概仓位 |

### ✅ 右侧共振（市场确认）

| 事件类型 | 示例 | 传导逻辑 |
|---------|------|---------|
| 投行评级上调 | 高盛上调腾讯目标价 | 外资定价权，机构建仓 |
| 港股通大额流入 | 单日净流入 >50亿 | 南向资金抢筹 |
| 牛熊证重货区变动 | Call证未平仓量上升 | 散户情绪转向 |

### ❌ 噪音过滤

| 事件类型 | 原因 |
|---------|------|
| 日常小幅波动 | 无基本面变化 |
| 分析师例行评级 | 滞后指标 |
| 公司日常公告 | 无重大影响 |
| CEO采访言论 | 往往是PR |

## 工作流程

### 第一步：左侧信号扫描

1. 使用 `fetch_hkex` 获取回购/减持公告
   - 重点关注：腾讯(00700)、美团(03690)、阿里(09988)、小米(01810)
   - 回购金额 > 1亿港元 为重大信号

2. 使用 `fetch_financial_news` 获取政策快讯
   - 关键词：港股、美联储、监管、版号、回购、降息
   - 来源：财联社（国内政策）、华尔街见闻（全球宏观）

### 第二步：传导逻辑推演

对发现的事件，分析影响路径：
- 基本面影响：对业绩/估值的影响
- 资金面共振：南向/外资的反应
- 宏观环境：美联储、国内政策的配合

### 第三步：生成异动一页纸

使用 `save_one_pager` 保存分析结果（domain="stocks"）

## 异动一页纸模板

使用 `save_one_pager` 工具时，填入以下字段：

```
concept_name: "{股票名称} ({股票代码}) - {事件类型}"
definition: "{事件描述：发生了什么}"
pain_point: "{传导逻辑：为什么影响}"
old_paradigm: "{之前的市场预期/估值}"
new_paradigm: "{事件后的市场预期/估值}"
production_impact: "{操作建议}"
adoption_cost: "{风险提示}"
github_url: ""
source_url: "{新闻/公告链接}"
```

## 输出示例

```markdown
# 腾讯控股 (00700.HK) - 游戏版号获批

## 技术定义 (What)
国家新闻出版署发布最新一批进口游戏版号，腾讯旗下核心动作手游获批。

## 行业痛点 (Why)
1. **基本面修复**：该游戏海外已验证，获批意味着下半年国内游戏流水有确定性支撑。
2. **估值逻辑**：游戏监管环境释放稳定信号，有利于外资科技基金回补中概仓位。
3. **宏观共振**：恒指筑底期，权重股获alpha催化，易带动恒生科技指数反弹。

## 旧范式 vs 新范式
- **旧做法**：市场担忧游戏监管不确定性，估值受压制
- **新做法**：版号获批释放稳定信号，估值有望修复

## 生产力影响 (How)
若开盘回踩支撑位，可考虑右侧分批布局。结合CatBoost模型计算仓位风险。

## 采用成本
游戏流水兑现需要时间，短期仍有波动风险。

## 核心线索
- GitHub：
- 来源：国家新闻出版署公告
- 发布时间：2026-06-13
```

## 注意事项

1. **时效性优先**：港股对政策敏感，尽快完成判断
2. **区分左右侧**：左侧是机会，右侧是确认
3. **关注外资定价权**：投行评级对港股影响大
4. **噪音过滤严格**：99%的新闻是噪音，只推送重大事件
5. **设置 domain="stocks"**：保存时指定股票子目录
