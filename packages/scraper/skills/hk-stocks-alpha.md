# 港股 Alpha 事件捕获技能

捕捉港股市场的 alpha 事件：政策驱动、资金流向、投行评级、衍生品异动。

## 领域特点

港股具有"多源共振"特性：
- **南向资金**：港股通净流入，内地政策影响
- **北向/外资**：美联储利率、外资投行评级
- **衍生品**：牛熊证、期权重货区

## 判断标准

### ✅ 左侧信号（绝对优先）

| 事件类型 | 示例 | 传导逻辑 |
|---------|------|---------|
| 回购潮 | 腾讯/美团大额回购 | 历史上回购潮往往是见底信号 |
| 游戏版号获批 | 腾讯核心手游获批 | 基本面修复，估值重估 |
| 美联储降息预期 | 点阵图偏鸽 | 港元挂钩美元，流动性改善 |
| 内地政策松绑 | 互联网监管放松 | 外资回补中概仓位 |

### ✅ 右侧共振（市场确认）

| 事件类型 | 示例 | 传导逻辑 |
|---------|------|---------|
| 投行评级上调 | 高盛上调腾讯目标价 | 外资定价权，机构建仓 |
| 港股通大额流入 | 单日净流入 >50亿 | 南向资金抢筹 |
| 牛熊证重货区变动 | Call证未平仓量上升 | 散户情绪转向 |

### ❌ 噪音过滤

| 事件类型 | 原因 |
|---------|------|
| 日常小幅波动 | 无基本面变化 |
| 分析师例行评级 | 滞后指标 |
| 公司日常公告 | 无重大影响 |
| CEO采访言论 | 往往是PR |

## 工作流程

### 第一步：左侧信号扫描

1. 使用 `fetch_hkex` 获取回购/减持公告
   - 重点关注：腾讯(00700)、美团(03690)、阿里(09988)、小米(01810)
   - 回购金额 > 1亿港元 为重大信号

2. 使用 `fetch_financial_news` 获取政策快讯
   - 关键词：港股、美联储、监管、版号、回购、降息
   - 来源：财联社（国内政策）、华尔街见闻（全球宏观）

### 第二步：传导逻辑推演

对发现的事件，分析影响路径：
- 基本面影响：对业绩/估值的影响
- 走势共振：南向/外资的反应
- 宏观环境：美联储、国内政策的配合

### 第三步：生成交易快报

使用 `save_one_pager` 的 **Simple 模式** 保存报告：

```
title: "{股票代码} - {事件关键词}"
content: "{完整的 Markdown 报告内容}"
domain: "stocks"
```

**⚠️ 重要**：必须使用 Simple 模式（title + content），不要用结构化字段（concept_name 等），因为港股报告需要完全自定义格式。

## 交易快报模板

以下是 `content` 字段应使用的 Markdown 格式：

```markdown

- **事件**：{一句话描述发生了什么}
- **时间**：{事件发生日期}

## 市场信号解读

### 基本面影响

- 估值修复空间：{如：PE 从 15x 回归至 18x，约 20% 空间}

### 宏观环境配合

## 交易策略

- **理由**：{左侧信号还是右侧确认}

### 风险提示

## 数据跟踪清单
```

## 输出示例

```markdown
# 腾讯控股 (00700.HK)

## 事件概要
- **事件**：国家新闻出版署发布进口游戏版号，腾讯核心动作手游获批
- **时间**：2026-06-13
- **来源**：国家新闻出版署公告

## 市场信号解读

### 基本面影响
游戏监管释放稳定信号，估值有修复空间。
- 估值修复空间：当前 PE 15x，监管明朗后有望回归 18x（约 20% 空间）
- 业绩贡献：该游戏海外已验证，国内上线后预计贡献月流水 3-5 亿

### 资金面共振
南向资金持续流入，外资观望态度松动。
- 港股通：近5日累计净流入 32 亿，今日单日 +8.5 亿
- 外资动向：高盛维持买入评级，目标价 450 港元未调整

### 宏观环境配合
美联储降息预期升温，流动性环境改善。
- 流动性：点阵图显示年内可能降息 1 次，港元压力减轻
- 政策风向：互联网监管基调转向"支持平台经济发展"

## 交易策略

### 方向判断
- **判断**：看多
- **理由**：左侧信号（版号获批）+ 右侧确认（港股通流入加速）

### 操作建议
- **入场时机**：开盘若回踩 380 支撑位企稳，可分批入场
- **仓位管理**：建议 15% 仓位，CatBoost 模型风险值 0.35（中等）
- **止损位**：365 港元（支撑位下方 4%）

### 风险提示
1. 游戏上线流水兑现需 2-3 个月，短期无业绩支撑
2. 美联储降息节奏可能推迟，影响外资回流节奏
3. 恒指整体处于筑底期，系统性风险仍存

## 数据跟踪清单
- [x] 港股通每日净流入（盯盘）
- [ ] 牛熊证重货区分布（每日更新）
- [ ] 投行评级变动（每周跟踪）
- [ ] 公司公告回购进度（每周更新）
```

## 注意事项

1. **时效性优先**：港股对政策敏感，尽快完成判断
2. **区分左右侧**：左侧是机会，右侧是确认
3. **关注外资定价权**：投行评级对港股影响大
4. **噪音过滤严格**：99%的新闻是噪音，只推送重大事件
5. **使用 Simple 模式**：必须用 title + content 保存，不要用结构化字段
6. **量化优先**：估值、仓位、止损位尽量给出具体数值
