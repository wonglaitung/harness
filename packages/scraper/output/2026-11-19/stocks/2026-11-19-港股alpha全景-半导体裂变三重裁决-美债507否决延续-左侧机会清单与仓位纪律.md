**这是本 Agent 必须诚实记录的一次误判**。11-18 报告写的是"谨慎看多，不追高，等回踩 5 日线"。方向判断（板块会回落）对了，但**幅度判断严重错误**——不是"回踩"，是"崩塌"。教训：**在高利率环境下，高估值概念股的"回踩"往往会演变为"戴维斯双杀"，不能按常态波动幅度设止损**。

### 裂变的方向：谁在被奖励，谁在被惩罚

| 细分 | 标的 | 今日表现 | 现金流特征 | 市场态度 |
|------|------|---------|-----------|---------|
| **GPU / 算力故事** | 天数智芯 09903 | **-17.8%** | 亏损，靠融资 | ❌ 惩罚 |
| **GPU / 算力故事** | 壁仞科技 06082 | **-5.54%** | 亏损，靠融资 | ❌ 惩罚 |
| **晶圆代工 / 现金流** | 华虹宏力 01347 | **+10%（84.7）** | 有产能、有订单、有正现金流 | ✅ 奖励 |

**传导逻辑（本次扫描最重要的结构性发现）**：
```
10Y 5.07% 高利率
   ├─ 长久期资产（亏损型 GPU，估值全靠远期叙事）→ DCF 分母端被极致压缩 → 杀估值
   └─ 短久期资产（晶圆代工，即期现金流可验证）→ 相对折价优势 → 资金避险式流入
```

这不是"半导体走强"或"半导体走弱"，而是**同一条产业链内部按久期重新定价**。任何把半导体当作一个整体板块来交易的框架，在今天都会失效。

| **基本面支撑** | ✅ 晶圆代工是重资产、有实际产能利用率、有即期现金流，不依赖远期叙事 |
| **右侧确认** | ✅ +10% 是当日最强势的价格确认（板块内唯一） |
| **宏观约束** | ❌ 10Y 5.07% 仍压制整体估值上限 |
| **追高风险** | ❌ **+10% 当日入场违反技能纪律**（禁止追高，尤其短期涨幅集中） |

### 交易策略（严格）
- **方向**：**看多，但当日不追**
- **入场时机**：**必须等回踩**。等回调至 +10% 涨幅的一半以内（即涨幅收敛至 5% 以下），并出现缩量企稳的确认 K 线
- **仓位**：**≤8%**（单一个股，宏观否决下从严）
- **止损位**：以今日启动前的价格（84.7 / 1.10 ≈ **77.0 港元**）作为本轮启动位，跌破即离场
- **失效条件**：若明日代工端跟随 GPU 一同下跌 → 说明是"补跌"而非"换庄"，逻辑根本证伪，无条件离场

### 风险提示
1. **+10% 是盘中数据，非收盘价** — 港股盘中急涨后炸板（回吐）极为常见，需以收盘价重新评估
2. **换庄 ≠ 反转**：资金从 GPU 流向代工，可能是**板块内避险**而非**板块整体看多**。若是后者，代工涨完也会补跌
3. **单日孤证**：仅一日数据，无法区分"趋势启动"与"脉冲异动"。需连续 2-3 日验证
4. **宏观否决未解除**：10Y 5.07% 环境下，任何做多的预期收益须打 6-7 折
