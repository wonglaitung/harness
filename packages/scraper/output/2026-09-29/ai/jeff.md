# Jeff

## 技术定义 (What)
对 Qwen3.5 与 Gemma 4 微调得到的 0.8B–2B 小模型，用于零样本分类/决策。用自然语言描述情境与选项，单次前向即返回每个选项的校准概率，无需生成文本或解析，格式与 Jev（System One / 类型化决策模型）完全兼容。

## 行业痛点 (Why)
大模型执行结构化决策（路由、意图、审核标签）时又慢又贵，还要文本解析；Jev 需要更大模型和云端推理。

## 旧范式 vs 新范式
- **旧做法**：用大模型生成文本再解析，或 27B 级 Jev 模型云端 API 推理。
- **新做法**：0.8B–2B 级本地模型，22–49ms/决策，单次前向直接输出校准概率，可在家用单 GPU 训练（0.8B 约 2 小时）。

## 生产力影响 (How)
将"类型化决策"这一 System One 范式下沉到边缘/本地，让任何开发者都能在家训练自己的快速决策模型，用于路由、审核、意图识别等高频分类任务。

## 采用成本
极低：依赖 AutoJev 公开配方，单 GPU 2–3.5 小时微调，MLX/PyTorch 均可运行。
