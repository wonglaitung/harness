## 触发原因

### 核心数据
- 金价 8 月反弹高点：**4696.79 美元/盎司**
- 当前：**3808 美元/盎司**附近
- 区间累计跌幅：**近 -19%**

### 传导逻辑
```
金价 -19% → 黄金开采/冶炼企业盈利预期下修 → EPS 端实质恶化
                                          ↓
                          这不是情绪杀，是分子端下修
```

### 为何不是逆向机会
| 判断维度 | 结论 |
|---------|------|
| 下跌性质 | **基本面驱动**（金价 = 收入直接变量），非流动性错杀 |
| 跌幅归因 | 金价 -19% 直接映射，估值未压缩反而可能被动抬升 |
| 宏观方向 | 美债 10Y **5.10%** 高位 → 实际利率高企 → 压制无息资产，**利空尚未出尽** |
| 板块同步性 | 4 只齐跌 -4~-5.7% → 系统性重估，非个股事件 |

## 历史关联分析

### 相关历史信号
- **2026-11-18（同日全景报告）**：消费/金饰股集体走高 — 周生生 +4%、老铺黄金 +3.64%（**金饰 ≠ 黄金开采**）
- **2026-11-18**：消费轮动接棒 AI，黄金消费被列入轮动受益名单

### 关键区分（本次最重要的认知修正）
```
金饰零售（老铺黄金、周生生）→ 成本端受益金价回落 + 消费属性 → 涨
黄金开采（紫金黄金国际、灵宝）→ 收入端受损金价回落 → 跌
```
**同日出现「金饰涨、金矿跌」的分化，正是金价下跌逻辑的教科书式验证** — 说明这不是板块错杀，而是产业链内部的正确再定价。

### 判断对比
- **历史判断（同日全景）**：黄金消费板块性右侧共振
- **当前判断**：**黄金开采 = 左侧假机会，明确回避**；金饰零售逻辑反向成立
- **调整理由**：不能把「黄金概念」当同质板块处理，必须拆开采 vs 零售

## 风险评估（若逆势做多的具体风险）

1. **宏观持续施压**：美债 10Y 5.10% 高位僵持、降息预期关闭 → 实际利率居高，黄金无催化
2. **下修未完成**：金价 -19% 尚未充分反映在卖方盈利预测中，后续存在**盈利预测下调**的第二波杀跌
3. **技术面无支撑**：19% 跌幅属中期趋势反转级别，非短期回调，缺乏「跌幅够深」的反弹依据
4. **价值陷阱特征**：低 PE 是盈利高点造成的假象，金价继续下行将推升 PE
5. **禁止交易窗口叠加**：港股处业绩期（互联网龙头密集交卷）+ 美债高位，系统性波动放大

## 交易策略

- **方向**：**回避**（不做多、不抄底）
- **若已持仓**：反弹至 5 日均线减仓，不做补仓摊平
- **反向机会（唯一可考虑）**：若坚信金价见底 → 买**金饰零售**（成本端受益）而非金矿，或直接做多黄金 ETF 而非个股（避免经营杠杆放大）
- **观察触发点**：金价站稳 3800 美元/盎司且美债 10Y 回落至 5.00% 下方，才重新评估金矿
