## 技术定义 (What)
一个"模型牧场"：作者本人是 1 型糖尿病患者，也是唯一受试者。他把 **35 个血糖预测模型**（persistence、线性外推、ridge AR、XGBoost、LightGBM、LSTM、MiniRocket、Chronos-2、TimesFM 2.5、Timestral 5M–209M、自研 D16 DILATE / D16 MSE）在**自己的 CGM 数据**与**公开 MetaboNet** 两个域上同台评测。配套自建工具链：`T1DMSIM`（合成 CGM 轨迹，因 UVA/Padova 在笔记本上太慢）、`T1DMDROID`（手机上跑模型）、D16 系列（宽 16 的小 transformer，用 DILATE 或 MSE 损失，合成预训练后加 LoRA 轻调）。

## 行业痛点 (Why)
个性化时序预测（血糖、睡眠、心率）习惯"人群训练 + 人群指标"，但服务对象是个体。个人数据量小、标注贵、隐私不能外包；同时领域评测普遍只报平均 RMSE，不报对低血糖等关键事件的捕获率——于是"能发论文的模型"与"对这个人有用的模型"长期错位。

## 旧范式 vs 新范式
- **旧做法**：人群数据训练/评估，报均值 RMSE，假设指标提升即个体获益；个人化 = 再训一个大模型；数据依赖重型模拟器或不可得队列。
- **新做法**：以个体为基准域，几十个异构模型同台 + 统计检验判等价；自建合成数据器解除依赖；用极小 LoRA 做个性化；并报负结果与事件级指标。

## 生产力影响 (How)
- 60min 预测：3771 参数 LoRA 把 D16 DILATE 从 26.1 → **22.8**、D16 MSE 从 27.1 → 23.5（MetaboNet：36.6→34.6 / 36.7→35.1）。
- 自身数据上排 **3/35（22.8）**，与最优 XGBoost / LightGBM（均 22.4）在 Wilcoxon 下**不可区分**。
- 预警提前量 **40–50 分钟**（XGBoost 30 分钟）；60min 低血糖捕获率 **40–47%**（XGBoost 28%）。
- 负结果同样公开：MetaboNet 120min 上 LoRA 使 D16 DILATE 从 48.0 **恶化**到 50.4；MetaboNet 各低 RMSE 模型几乎抓不到低血糖（XGBoost 0%、T1DMAI 6–8%），而线性外推抓到 58%。
- 规模不敏感：Timestral 5M 与 209M 在 60min 相差 <0.4 mg/dL（自身数据）。

## 采用成本
个人研究者：笔记本 + 自有 CGM + 开源三件套，时间以周计。组织：n=1 结论不可外推，必须重建自己的基准域；且受监管边界严格限制。

## 采用案例
- **自身部署**：D16 + LoRA 通过 T1DMDROID 在手机上运行，同时读取多个 CGM。
- **跨域验证**：同批模型在私有（自身）与公开（MetaboNet）两域交叉，暴露"人群最优 ≠ 个体最优"（XGBoost 在自身域最优，微调 Timestral 209M 在 MetaboNet 最优）。

## 风险/局限
- **不可外推**：n=1 的排名不构成人群结论；作者原话"All models suck"。
- **非医疗器械**：明确不用于诊断或胰岛素剂量计算，无监管许可。
- **统计功效有限**：Wilcoxon 只能判"不可区分"，无法判等价。
- **AI 生成代码占比高**：README 自述大部分代码由 AI 写成，需自行审计。
