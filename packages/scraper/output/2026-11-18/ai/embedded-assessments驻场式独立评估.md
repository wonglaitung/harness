# Embedded Assessments（驻场式独立评估）

## 技术定义 (What)
Embedded Assessment 指独立外部评估机构（Apollo Research、METR、Transluce、Goodfire）被长期"嵌入"到模型实验室内部，以驻场方式获得与内部研究员同级的资源访问权——包括模型 checkpoint、源码、训练与评测数据、监控系统、训练干预记录，以及与一线研究者对话——对安全声明（safety case）进行持续数周至数月的独立核查，而非仅通过公开 API 做黑盒测试。OpenAI 同时发布了配套的 scoping/onsite/security/IP 替代方案等协议草案，因为该形态此前尚无行业标准。

## 行业痛点 (Why)
第三方评测长期停留在"给一个 API 端点、跑一批 prompt"的黑盒层面，无法验证实验室关于"训练没有激励颠覆行为""监控能发现异常""后训练对齐评测覆盖充分"这类内部过程性声明。外部审计者看不到 checkpoint 与训练轨迹，就无法独立复现失败模式，安全声明实际上不可证伪。

## 旧范式 vs 新范式
- **旧做法**：外部红队/评测 = 发布前拿黑盒 API 打靶，产出一次性的评测分数或漏洞列表；实验室自评自证，外部只能相信公开报告。
- **新做法**：外部评测 = 驻场嵌入式审计。评估机构进入内部系统、按自己的优先级迭代搜索与 elicit 实验、在训练完成后仍可回溯选定 checkpoint 与监控记录，并把"是否触发监控"本身作为被评估对象（如 METR 同时对最大 RL run 与监控系统做双重评估）。IP 敏感项以"与内部研究员配对执行分析"替代直接给出权重。

## 生产力影响 (How)
对 AI 安全与合规团队：安全声明从"实验室自述"变为"可被外部复核的证据链"，模型发布决策与 safety case 必须准备可审计材料（训练干预记录、监控命中记录、评测覆盖矩阵）。对企业采购方，这提供了新的供应商尽调维度：该实验室是否接受驻场审计、审计范围是否覆盖其最大训练 run。

## 采用成本
实验室侧成本高：需要提供安全隔离的驻场环境、专用设备、脱敏后的数据访问通道、法务协议（保密与独立性条款），以及约 4 家机构的并行协调开销。评估机构侧需要长周期人力投入。短期无法标准化，OpenAI 明确表示协议会随实践演进。
