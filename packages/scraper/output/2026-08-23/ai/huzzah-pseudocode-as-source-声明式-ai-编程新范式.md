## 技术定义 (What)
Huzzah 是一种"伪代码即源码"的 AI 编程范式。开发者创建 `.hz` 文件，用类似伪代码的简洁语法描述程序应该做什么（声明式），保存后 AI 自动生成真实代码。修改时只需更新伪代码，Huzzah 捕获 diff 作为 LLM Prompt，仅重新生成受影响部分。伪代码持久保留为人类意图的正式记录。

## 行业痛点 (Why)
当前 AI 辅助编程存在根本性矛盾：
- **Prompt 瞬时的**：聊天记录可能被丢弃，人类意图没有永久记录
- **自然语言低效**：大量社交性词汇（"请帮我……"）消耗 Token 但零信息量
- **命令式重复**：同一需求的修改需要多次发 Prompt 描述变更
- **文档漂移**：代码生成后需要额外维护文档，与代码分离

## 旧范式 vs 新范式
- **旧做法**：在 Chat 中写长文本 Prompt → AI 生成代码 → 修改时再写 Prompt → Prompt 消失、代码与意图脱节
- **新做法**：写伪代码 `.hz` 文件 → 保存自动生成真实代码 → 修改伪代码即修改代码 → 伪代码 = 开发文档 = 人类意图的永久记录

## 生产力影响 (How)
- **Token 效率**：伪代码比等价自然语言 Prompt 简洁 5-10 倍
- **认知减负**：写伪代码比写英文 Prompt 更接近开发者的自然思维模式
- **文档自动生成**：伪代码即文档，不再需要额外维护
- **跨语言复用**：同一份语言无关伪代码可生成多语言实现

## 采用成本
- 学习曲线低：伪代码是开发者的第二天性
- 开源（GitHub），实验阶段
- 局限性：更适合新代码或独立模块，现有大型代码库迁移困难
