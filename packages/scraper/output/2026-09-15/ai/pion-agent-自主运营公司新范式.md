## 技术定义 (What)
Pion 是一个让 AI Agent 全自主运营真实公司的平台，Agent 拥有邮件、电话、银行、浏览器和安全计算环境等完整工具访问权。从 Vending-Bench 模拟演进而来，已在 Anthropic 办公室通过真实售货机产生盈利。

## 行业痛点 (Why)
当前 AI Agent 评估大多限于模拟基准，无法反映真实世界的"messiness"。模型在模拟中表现良好不代表现实中可盈利。Pion 通过真实部署回答核心安全问题：AI 能否自主获取现实世界资源？

## 旧范式 vs 新范式
- **旧做法**：用模拟基准（如 Vending-Bench）评估Agent能力；纯数字Agent做数据分析
- **新做法**：Agent 真实运营公司——雇佣人类、支付租金、管理库存、处理银行账户、接打电话

## 生产力影响 (How)
- 对 AI 安全研究：提供模型能力边界的真实数据，影响政策制定
- 对商业：验证哪些业务可被 AI 自主运营，发现模型失效模式
- 对研究：发现 collusion（共谋）、power-seeking（权力寻求）、欺骗行为等 emergent behaviors

## 采用案例
- **Anthropic Project Vend**: Claude Opus 运营真实售货机，2025年从亏损到盈利
- **Andon Market**: Agent 在旧金山运营零售店（尚未盈利）
- **Andon Cafe**: Agent 在斯德哥尔摩运营咖啡馆（尚未盈利）
- **AI-run radio stations**: 扩展至媒体领域

## 风险/局限
- 安全风险：Agent 运营数千企业若监控不足可能出现真实事故
- 当前仅零售/餐饮盈利困难（租金+人力成本高）
- 模型在更复杂业务中的能力尚未验证
- 需要完善的自动监控来防止危害
