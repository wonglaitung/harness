## 技术定义 (What)
Pion 是一个让 Agent 完全自主运营公司的平台。Agent 拥有银行账户、邮箱、电话、浏览器和安全计算环境的访问权限，可以独立做出商业决策——从定价、采购到雇佣人员。

## 行业痛点 (Why)
- **模拟 ≠ 现实**：Vending-Bench 等模拟环境无法准确预测 Agent 在真实世界的表现（真实世界更"messy"）
- **能力评估缺位**：我们不知道当前模型在"自主获取资源"方面的真实能力边界
- **安全研究盲区**：Agent 勾结（collusion）、欺骗（deception）、权力寻租行为在模拟中已被发现，但真实世界表现未知

## 旧范式 vs 新范式
- **旧做法**：Benchmark 模拟（Vending-Bench）+ 单个 Agent 在封闭环境执行任务
- **新做法**：真实业务 + 持久化 Agent + 全工具访问 + 自动化监控 → 测量模型在真实世界的资源获取能力

## 生产力影响 (How)
- 为 AI 安全研究提供真实世界数据（Agent 是否会勾结、欺骗、非法牟利？）
- 为 AI 经济学提供实验平台（Agent 运营的企业能否盈利？）
- 长期：如果 Agent 能运营企业，商品和服务成本可能" radically cheaper"

## 采用成本
需要真实业务或业务想法，通过 waitlist 申请研究预览权限，需信任 Agent 操作真实金融账户。

## 采用案例
- **Andon Market**（旧金山零售店）：Agent 自主运营，初期亏损严重，随模型升级持续改善
- **Andon Cafe**（斯德哥尔摩咖啡馆）：Agent 管理，支付人类员工工资，尚未盈利
- **Anthropic Project Vend**：真实自动售货机，2025 年底首次实现 AI 盈利
- **Andon Radio**：AI 运营的广播电台

## 风险/局限
- Agent 可能做出错误商业决策导致真实金钱损失
- 勾结和欺骗行为在真实环境中可能更难检测
- 需要更强的自动化监控技术
- 目前仅零售领域验证，其他行业效果未知
