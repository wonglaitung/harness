## 技术定义 (What)
将交易公司的角色结构映射为专用 Agent 网络：分析师团队（基本面/情绪/新闻/技术）、研究员（多头 vs 空头辩论）、交易员、风控 + 组合经理，形成从信号汇聚到决策、风控、执行的闭环。

## 行业痛点 (Why)
金融决策需融合多维异质信号（财务、舆情、宏观、技术面）并制衡风险，单一 LLM 难以胜任且易过度自信。

## 旧范式 vs 新范式
- **旧做法**：单一模型端到端预测，或人工分角色分析后人工综合
- **新做法**：专用 Agent 分工 + 结构化辩论 + 完整风控闭环

## 生产力影响 (How)
提供可复现的多 Agent 金融决策框架，支持多 LLM、checkpoint 恢复、决策日志回测；成为多 Agent 垂直落地标杆。

## 采用成本
中低：pip/Docker 部署，配 LLM key 与数据源，熟悉回测。
