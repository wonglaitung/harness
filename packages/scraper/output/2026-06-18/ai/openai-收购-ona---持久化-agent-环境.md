# OpenAI 收购 Ona - 持久化 Agent 环境

## 技术定义 (What)
Ona 被 OpenAI 收购，其技术为 Codex 提供安全、持久的云执行环境，让 Agent 能够在用户关闭设备后继续工作。这是企业级 Agent 部署的关键基础设施：客户控制的执行模型，Agent 在组织的云环境中运行，满足安全、治理和合规要求。

## 行业痛点 (Why)
现有 AI Agent 工具受限于会话时长和设备绑定，无法执行需要数小时或数天的长周期任务。企业部署 Agent 时担心安全边界、数据隐私、审计日志等问题，缺乏符合企业级要求的执行环境。

## 旧范式 vs 新范式
- **旧做法**：Agent 任务在用户本地机器或临时会话中运行，一旦设备关闭或会话结束，任务中断。企业需要保持连接才能完成复杂工作，无法真正"委托"任务。安全性和合规性难以保证。
- **新做法**：Agent 在客户控制的持久云环境中运行，即使笔记本电脑关闭也能继续工作。支持长时间运行的任务（测试、问题修复、应用现代化、漏洞修复等），提供完整的审计日志、权限范围控制、安全边界隔离，满足企业级部署需求。

## 生产力影响 (How)
让企业能够安全地部署生产级 Agent，处理复杂的跨系统工作流。从实验性使用转向生产环境部署，真正实现"委托任务而非监控执行"的自主工作模式。Codex 用户数已超 500 万，增长 400%。

## 采用成本
收购待监管审批。集成后将成为 Codex 企业版功能，组织需要配置云环境、设置权限边界、学习 Agent 管理流程。对已有云基础设施的企业，采用成本较低。
