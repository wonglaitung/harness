# Dreaming Memory - ChatGPT 记忆合成架构

## 技术定义 (What)
Dreaming 是 ChatGPT 的新记忆架构，通过后台进程自动从对话历史中合成记忆，而非仅在对话中显式保存。它优化三个目标：新鲜度（保持当前）、连续性（保持上下文）、相关性（优先重要信息），解决传统记忆的陈旧、错误和可扩展性问题。

## 行业痛点 (Why)
传统 Saved Memories 需要用户显式要求"记住"，且容易过时、不准确。用户需要重复提供相同上下文，ChatGPT 像是"只记了几个笔记但其他都忘掉"的人。在数亿用户和多年时间跨度下，记忆系统面临陈旧性、正确性和可扩展性挑战。

## 旧范式 vs 新范式
- **旧做法**：Saved Memories（2024）：仅在对话中显式保存，依赖强提示词触发。记忆列表静态，容易过时，需要手动管理。ChatGPT 只能访问明确保存的记忆，无法从对话历史中自动学习。
- **新做法**：Dreaming V3（2026）：后台自动合成记忆，从多轮对话中学习，无需显式请求。记忆总结页可查看和管理，支持"持续跟随偏好"、"保持时间敏感性"（如"下周六生日派对"随时间更新）。已作为独立记忆系统，不再依赖 Saved Memories。

## 生产力影响 (How)
让 ChatGPT 真正"了解"用户，减少重复上下文提供。对于长期项目（如购买兼容摄影设备），ChatGPT 能记住之前的讨论并提供个性化建议。适合 Plus 和 Pro 用户，未来扩展到 Free 和 Go 用户。

## 采用成本
已向美国 Plus/Pro 用户推出，未来数周扩展到其他国家。用户可在记忆设置中启用"参考聊天历史"和"使用保存的记忆"，查看记忆总结页。无需额外学习成本，自动生效。
