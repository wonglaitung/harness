# OpenMontage - Agentic Video Production

## 技术定义 (What)
OpenMontage 是全球首个开源的 Agent 驱动视频生产系统，包含 12 条管道、52 个工具、500+ Agent 技能。它将 AI 编程助手转变为完整的视频制作工作室，用户用自然语言描述需求，Agent 自动完成研究、脚本撰写、资产生成、剪辑和最终合成。

## 行业痛点 (Why)
传统视频制作需要专业技能、昂贵软件和大量人工操作。现有 AI 视频工具仅能生成短片段或简单动画，无法处理完整的视频生产流程（从概念到成品）。企业需要端到端自动化视频生产能力。

## 旧范式 vs 新范式
- **旧做法**：视频制作流程割裂：策划、脚本、拍摄、剪辑、配音、字幕、特效等环节分别使用不同工具，需要专业人员手动协调。成本高、周期长、门槛高。
- **新做法**：使用 Agent 自动编排整个视频生产流水线：从参考视频分析、概念生成、工具路径规划、成本预估，到资产自动生成、剪辑合成、质量检查，全程 AI 自主完成。支持真实视频制作（非仅图片动画），成本可低至 $0.15-1.33。

## 生产力影响 (How)
将视频制作从专业技能转变为自然语言描述，大幅降低制作门槛和成本。支持多种风格（电影级、皮克斯动画、吉卜力风格等），适合营销视频、教学视频、产品演示等场景。企业可以用极低成本快速产出高质量视频内容。

## 采用成本
需要 Python 3.10+、FFmpeg、Node.js 18+，以及 AI 编程助手（Claude Code、Cursor、Codex 等）。可选配置多个 API 密钥（图像、视频、音乐、TTS 等），每个密钥都是可选的。学习曲线中等，主要是理解管道和工具选择逻辑。
