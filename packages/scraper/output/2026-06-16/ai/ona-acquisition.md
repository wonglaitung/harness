# Ona Acquisition

## 技术定义 (What)
OpenAI 收购 Ona 以将 Codex 从"会话绑定工具"升级为"持久化 Agent 云环境"。Ona 提供安全的云端执行环境，让 AI Agent 能够在用户关闭笔记本电脑后继续工作数小时甚至数天，访问企业内部工具、系统和数据，完成长期任务。

## 行业痛点 (Why)
现有 Codex 的局限：1）会话绑定（关闭浏览器=任务中断）；2）设备依赖（必须在发起任务的机器上运行）；3）安全隔离不足（难以在企业私有云中部署）；4）长时间任务无法执行（测试套件、代码重构、漏洞修复需要数小时）。

## 旧范式 vs 新范式
- **旧做法**：Agent 工作在用户的本地环境或浏览器会话中，任务执行时间受限于会话时长。用户需要保持设备在线，无法"提交后离开"。企业难以控制 Agent 的运行边界、访问权限、审计日志。
- **新做法**：Agent 在企业控制的云端环境中持久运行，用户可以随时从任何设备检查进度、提供指令、审查结果。Agent 拥有独立的工作空间、凭证作用域、活动日志。企业可以在自己的 VPC 中部署，满足安全与合规要求。

## 生产力影响 (How)
对开发者的革命性影响：1）解锁"提交后忘记"工作流（下班前提交任务，第二天验收）；2）长时间任务成为可能（重构代码库、运行完整测试矩阵、迁移数据库）；3）团队协作新范式（多人监控同一个 Agent 工作流）；4）企业级 Agent 部署路径清晰化。

## 采用成本
收购完成后集成到 Codex Enterprise（预计付费功能）。对于企业：需要配置云端执行环境、设置安全策略、定义访问边界。对于个人开发者：等待 OpenAI 后续产品发布。时间成本：中高。金钱成本：企业级定价。
