# Dreaming Memory

## 技术定义 (What)
OpenAI 提出的后台记忆合成系统，通过"做梦"（Dreaming）进程在后台自动整理、更新、压缩多轮对话记忆，实现记忆的新鲜度、连续性和相关性优化。区别于传统的"saved memories"（显式记住指令），Dreaming 让 ChatGPT 能够自动从自然对话中学习用户偏好、项目背景和约束条件，无需用户明确要求"记住这个"。

## 行业痛点 (Why)
传统记忆系统的三大痛点：1）陈旧性（saved memories 随时间过期）；2）被动性（需要显式指令"记住X"）；3）碎片化（记忆是孤立条目，缺乏上下文关联）。当用户数达数亿、时间跨度数年时，这些问题导致记忆质量急剧下降。

## 旧范式 vs 新范式
- **旧做法**：用户必须明确说"记住我下周要去新加坡"，ChatGPT 才会写入 saved memories 列表。记忆是静态的，会随时间变得陈旧或不相关。用户需要手动管理记忆条目。
- **新做法**：Dreaming 进程在后台自动分析历史对话，合成出结构化的记忆摘要。系统主动识别用户偏好、项目背景、时间约束，并持续更新。用户可在 Memory Summary 页面查看、编辑、指导记忆内容。记忆是动态的、可追溯的、持续新鲜的。

## 生产力影响 (How)
对开发者的影响：1）减少重复沟通成本（用户不用反复说明背景）；2）提升长期任务成功率（Agent 能记住跨会话上下文）；3）降低 token 消耗（压缩历史对话）；4）为 Agent 长期工作流奠定基础（类似 Ona 收购的战略协同）。

## 采用成本
免费功能（ChatGPT Plus/Pro 用户）。对于开发者：需要理解新的记忆管理接口，设计提示词时考虑记忆持续性。学习成本低，主要是思维模式转变。
