# Understand-Anything

## 技术定义 (What)
将任意代码库、知识库或文档转化为可探索、可搜索、可提问的交互式知识图谱。通过多 Agent 流水线分析代码，提取文件、函数、类和依赖关系，生成可视化 Dashboard。

## 行业痛点 (Why)
新加入团队时面对 20 万行代码无从下手；代码审查时缺乏全局视角；知识传递依赖人工文档；代码结构理解成本高。

## 旧范式 vs 新范式
- **旧做法**：逐文件阅读代码；依赖注释和文档；使用 IDE 的搜索功能；人工绘制架构图；知识碎片化难以系统性理解。
- **新做法**：一键生成代码知识图谱 → 可视化探索架构层级 → 模糊/语义搜索定位功能 → 引导式教程按依赖顺序学习 → 差异影响分析预测变更影响 → 多角色自适应 UI（开发者/PM/高级用户）。

## 生产力影响 (How)
**大幅降低代码理解成本**：新人 onboarding 时间从数周缩短到数小时。**提升代码审查质量**：可视化依赖关系，提前发现架构问题。**加速知识传递**：自动生成架构文档，无需人工维护。**支持多平台**：Claude Code、Codex、Cursor、Copilot、Gemini CLI 等 10+ 平台原生支持。

## 采用成本
**时间成本**：一键安装 `/plugin install understand-anything`，首次分析 5-30 分钟（取决于代码库大小）。**学习成本**：零学习曲线，自然语言提问即可。**计算成本**：首次分析消耗 LLM tokens，增量更新仅重分析变更文件。
