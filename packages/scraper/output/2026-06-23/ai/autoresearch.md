# autoresearch

## 技术定义 (What)
一个让 AI Agent 自主进行模型训练实验的框架。Agent 在固定 5 分钟时间预算内修改代码、训练模型、评估结果、迭代改进。人类通过编辑 program.md（Agent 指令）来"编程"研究流程，而非直接修改 Python 代码。

## 行业痛点 (Why)
AI 研究需要大量人工实验：调参、训练、评估、迭代。研究人员花费大量时间在重复性实验上，而非创新性思考。

## 旧范式 vs 新范式
- **旧做法**：人工设计实验 → 手动修改代码 → 训练模型 → 分析结果 → 迭代改进，每个实验周期数小时到数天
- **新做法**：Agent 驱动的实验循环：自动修改代码、训练、评估、决策（保留或丢弃），夜间完成 100+ 实验，人类早晨查看结果

## 生产力影响 (How)
将实验吞吐量提升 10-20 倍。一个研究人员可同时运行多个自主研究项目，AI Agent 充当 24/7 研究助手。

## 采用成本
中等：需要单张 NVIDIA GPU（推荐 H100），Python 3.10+，uv 包管理器。主要成本是 GPU 时间，适合有计算资源的研究团队。
