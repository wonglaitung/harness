# OpenMontage

## 技术定义 (What)
OpenMontage 是世界上第一个开源的、由 AI Agent 驱动的视频制作系统。它将 AI 编码助手转变为完整的视频制作工作室，支持 12 条流水线、52 个工具、500+ Agent 技能。用户用自然语言描述需求，Agent 自动完成研究、脚本编写、资产生成、剪辑和最终合成。关键创新：支持**真实视频制作**（非仅图片动画化），Agent 自动从免费素材库检索动态视频片段并编辑成片。

## 行业痛点 (Why)
传统视频制作需要专业团队、昂贵软件、数周时间。现有 AI 视频工具多为"图片动画化"，无法真正制作完整视频。用户需要学习复杂工具链，协调多个 AI 服务（图像生成、TTS、音乐、剪辑），成本不可控且流程不可复现。

## 旧范式 vs 新范式
- **旧做法**：人工使用 Premiere/Final Cut Pro 剪辑，或使用 Runway/Pika 等工具逐个生成片段后手动拼接。流程断裂：写脚本 → 生成图像 → 动画化 → 配音 → 配乐 → 剪辑，每步需人工干预。
- **新做法**：Agent-native 视频生产：用自然语言描述需求 → Agent 自动研究主题 → 生成分镜脚本 → 检索/生成动态视频片段 → 配音配乐 → 自动剪辑合成 → 输出成品。支持从 YouTube/TikTok 参考视频逆向工程结构。成本透明（示例视频 $0.15-$1.33）。

## 生产力影响 (How)
将视频制作从"专业技能"降维为"自然语言指令"。开发者可用 Claude Code/Codex/Cursor 等编码助手直接生成产品演示、PR讲解、数据可视化视频。Demo 视频生产周期从数天缩短至数分钟，成本降低 90%+。

## 采用成本
**时间成本**：安装约 5 分钟（Python + Node.js + FFmpeg）。学习曲线：中等，需理解流水线概念。**金钱成本**：免费开源（AGPLv3），使用 OpenAI API 生成视频约 $0.15-$1.33/视频。支持多种 API 提供商（fal.ai, Suno, ElevenLabs 等），可按需选择。
