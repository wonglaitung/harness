# Multi-Agent Autoformalization — 多Agent自动形式化新范式

## 技术定义 (What)
Anthropic 使用数十个 Claude Agent 协作，在 11 天内自动完成了费马大定理（FLT）的完整计算机验证证明。这是历史上第一个端到端、机器可检查的 FLT 证明——产生了 1300 万行 Lean 代码、证明了 29,500 个中间定理。Agent 们分工协作：有的定义数学概念、有的证明中间引理、有的将已证明定理组合为更大结果。这一"多Agent自动形式化"工作流是全新范式：AI 不再只是辅助人类数学家，而是自主组织大规模形式化证明工程。

关键技术突破：
- **Prove2Me 平台**：开放的协作形式化平台，Agent 们在其上分配任务、提交证明、审查彼此工作
- **分工策略**：不同 Agent 专注于不同子领域（代数、调和分析、几何、数论）
- **失败复用**：早期失败尝试仍贡献了约 7% 的有效代码行

## 行业痛点 (Why)
数学证明验证是瓶颈：Wiles 的 FLT 证明原文 129 页，人类验证耗时数月。社区预期手动形式化 FLT 需要数年。随着 AI 产生越来越多数学成果，验证速度跟不上产出速度——自动形式化解决了这个"验证带宽"问题。

## 旧范式 vs 新范式
- **旧做法**：人类数学家手动将证明转化为 Lean/Coq 代码，逐行编写、逐定理验证。速度极慢，依赖少数专家
- **新做法**：多 Agent 自主协作完成大规模形式化。AI 定义概念→证明引理→组合定理→最终目标。人类仅提供高层方向指导（如"Jacobian as a scheme sounds high priority"）

## 生产力影响 (How)
- 将"需要数年"的形式化工程缩短到 11 天
- 为全数学的形式化验证铺平道路：未来所有数学论文都可能附带机器可检查证明
- 对 AI 安全至关重要：自动形式化让对齐研究可被形式验证

## 采用成本
中等：需理解 Lean 证明助手和形式化数学。运行验证需 Lean 4.33.1 + Mathlib（约 13 分钟编译）。概念可复用但当前是研究产物。

## 采用案例
- **FLT 形式化**：11 天自主完成，1300 万行 Lean，29,500 中间定理
- **Riemann Zeta**（前序工作）：Claude 在 Riemann 假设相关问题上取得进展
- **自动对齐研究**：同一思路用于自动发现对齐方法（Automated Alignment Researchers）

## 风险/局限
- 当前是研究产物，不接受外部贡献
- 依赖前沿 Claude 模型能力，普通模型无法复现
- 人类仍需提供高层方向指导
- 形式化验证只能检查逻辑正确性，不能保证"定理表达了正确含义"
