## 技术定义 (What)

claude-red 是一套将攻防安全专业知识编码为结构化 SKILL.md 文件的系统。每个文件对应一个攻击面（如 SQL 注入、EDR 规避、ADCS 滥用），Claude 加载后即成为该领域的专家级红队操作员。技能按对话触发按需加载，不给上下文增加负担。

## 行业痛点 (Why)

传统安全测试依赖人类专家的多年经验和手动工具链。AI Agent 虽然通用但缺乏深度领域知识。prompt engineering 方式注入知识不系统、不持久、难以复用。

## 旧范式 vs 新范式

- **旧做法**：粘贴长 prompt → 每次都重新描述领域知识 → 质量不稳定 → 知识不可复用
- **新做法**：结构化 SKILL.md 文件 → 按需自动加载 → 专家级方法论 → 23 个领域 × 78 个技能可组合

## 生产力影响 (How)

- 将安全专家的隐性知识显性化为可复用的结构化模块
- AI Agent 从"通用助手"升级为"领域专家"
- 技能文件可审计、可改进、可共享
- 为所有垂直领域（医疗、法律、金融）的 AI 专业化提供模板

## 采用成本

零成本（MIT 开源），git clone 即用。学习曲线低：每个 SKILL.md 即独立模块。

## 采用案例

- 红队授权渗透测试：加载相应攻击面技能，Claude 成为全栈安全操作员
- Bug bounty 分类：按漏洞类型加载技能，快速定位利用路径
- CTF 准备/安全培训：按需加载不同领域技能进行针对性训练

## 风险/局限

- 仅适用于 Claude Skills 系统（生态锁定风险）
- 安全工具的双刃剑特性：同样可被恶意使用
- 技能质量取决于维护者专业水平
