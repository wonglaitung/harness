# OpenMontage

## 技术定义 (What)
OpenMontage 是首个开源 Agentic Video Production 系统，让 AI Coding Assistant 变成完整视频制作工作室。Agent 自主完成研究、脚本编写、资产生成、剪辑和最终合成，支持真实视频制作（非仅动画图片）。首创"从参考视频启动"模式，自动分析 YouTube/TikTok 视频的结构、节奏、风格并生成差异化方案。

## 行业痛点 (Why)
传统视频制作需要专业技能、昂贵工具和大量时间。AI 视频工具要么仅生成片段（如 Sora/Runway），要么需要手动拼接。开发者无法用自然语言端到端生成复杂视频内容。

## 旧范式 vs 新范式
- **旧做法**：旧做法：1) 专业视频编辑软件+ 专业团队；2) AI 视频生成工具生成片段 → 手动下载 → 剪辑软件拼接；3) 需要视频制作专业知识，无法自动化；4) 成本高昂（单视频 $50-500）
- **新做法**：新做法：1) 自然语言描述需求 → Agent 自主研究、写脚本、找素材、剪辑；2) 从参考视频启动，自动提取结构和风格；3) 支持 12 条管线（纪录片、动画、产品广告等），500+ Agent 技能；4) 成本极低（示例视频 $0.15-$1.33）

## 生产力影响 (How)
让任何开发者用自然语言制作专业视频，从"需要视频团队"变为"一个 Agent 搞定"。降低视频制作门槛 10-100 倍，成本降低 90%+。支持真实视频制作（免费素材库）和 AI 生成两种路径。

## 采用成本
低：Python 3.10+、FFmpeg、Node.js 18+，一条命令安装。API keys 可选（更多 keys = 更多工具），核心功能免费。学习曲线：自然语言交互，无需视频专业知识。
