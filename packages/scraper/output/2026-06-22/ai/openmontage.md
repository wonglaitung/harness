# OpenMontage

## 技术定义 (What)
OpenMontage 是全球首个开源的 Agent 驱动视频制作系统（Agentic Video Production System）。AI 编码助手（Claude Code/Cursor/Codex）可以自主完成从研究、脚本、素材生成、剪辑到最终合成的全流程视频制作。支持 12 条管道、52 个工具、500+ agent 技能。

## 行业痛点 (Why)
视频制作传统流程存在三大痛点：
1. **技能门槛高**：需要掌握脚本、拍摄、剪辑、特效、音效等多种专业技能
2. **工具链复杂**：涉及 10+ 种专业软件，学习成本高
3. **人力密集**：一个视频需要多人协作，周期长
4. **成本高昂**：专业设备和人力投入大
5. **AI 视频工具割裂**：各种 AI 生成工具独立运行，无法端到端自动化

## 旧范式 vs 新范式
- **旧做法**：**旧做法**：
1. 人工编写脚本 → 多次修改
2. 单独调用图像生成 API → 手动下载
3. 单独调用视频生成 API → 手动组合
4. 专业剪辑软件手动编辑 → Premiere/After Effects
5. 单独配音和音乐 → 多次调整同步
6. 手动字幕和特效 → 时间密集型
7. 总耗时：数天到数周
- **新做法**：**新做法**：
1. **自然语言驱动**：一句描述，agent 自主完成全流程
2. **管道编排**：12 条预定义管道，自动选择最优路径
3. **多源素材**：AI 生成（FLUX/Veo/Kling）+ 免费素材库（Pexels/Pixabay）
4. **自动剪辑**：Remotion 程序化视频合成
5. **智能配音**：自动 TTS + 字幕同步
6. **成本透明**：每个视频显示精确成本（如 $0.15-$1.33）
7. **质量保证**：自动验证（ffprobe、帧采样、音量分析）

## 生产力影响 (How)
**实际案例**：
- "SIGNAL FROM TOMORROW"（科幻预告片）：完整制作
- "THE LAST BANANA"（60 秒动画）：成本 $1.33
- "VOID"（产品广告）：成本 $0.69，仅用 OpenAI API
- "Afternoon in Candyland"（吉卜力风格）：成本 $0.15

**对开发者价值**：
1. 即刻可用：`make setup` 一键配置
2. 多平台支持：Claude Code/Cursor/Copilot/Windsurf/Codex
3. 可扩展：自定义工具和管道
4. 成本可控：精确预估和实际成本展示

## 采用成本
**时间成本**：10-20 分钟（安装 + 首个视频）
**金钱成本**：
- 开源免费
- 实际使用成本：$0.15-$5/视频（取决于工具选择）
**学习曲线**：低（自然语言驱动）
**系统要求**：Python 3.10+ / Node.js 18+ / FFmpeg
