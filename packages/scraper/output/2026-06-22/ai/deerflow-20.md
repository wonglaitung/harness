# DeerFlow 2.0

## 技术定义 (What)
DeerFlow 2.0 是字节跳动开源的超级 Agent 编排平台（Super Agent Harness），协调子代理（sub-agents）、记忆（memory）、沙箱（sandbox）和可扩展技能（skills）完成复杂任务。支持分钟到小时级别的长期任务，是首个明确提出"编排平台"概念的 agent 架构。

## 行业痛点 (Why)
现有 AI Agent 框架存在三大问题：
1. **单一能力限制**：大多数 agent 只能处理简单任务，无法完成跨领域的复杂工作流
2. **缺乏持久记忆**：会话间无法保持上下文，重复劳动
3. **安全隔离不足**：agent 执行代码缺乏沙箱保护，存在安全风险
4. **技能复用困难**：每个项目都需要重新开发相似能力

## 旧范式 vs 新范式
- **旧做法**：**旧做法**：
1. 单体 agent 架构 → 所有能力集中在一个 agent
2. 无状态对话 → 每次重新开始
3. 直接执行命令 → 无安全隔离
4. 硬编码工具 → 难以扩展
5. 人工编排多 agent → 效率低、易出错
- **新做法**：**新做法**：
1. **编排平台架构**：主 agent + 子代理分层协作
2. **持久化记忆**：跨会话知识保留（基于知识图谱）
3. **沙箱隔离**：支持 Docker/本地/远程容器
4. **可插拔技能系统**：200+ 内置技能，自定义扩展
5. **MCP 协议集成**：标准化工具接入
6. **多通道支持**：CLI + Web UI + IM（Telegram/Discord/Slack）

## 生产力影响 (How)
**典型应用场景**：
- 深度研究：多源信息检索、分析、总结
- 代码开发：完整项目从需求到部署
- 内容创作：脚本、图像、视频全流程
- 数据分析：ETL、建模、可视化

**对开发者价值**：
1. 一键启动：`make setup` 交互式配置
2. 多模型支持：OpenAI/Claude/DeepSeek/Kimi/豆包
3. 生产级部署：支持 Docker/K8s
4. 完整文档：官方网站 + 详细示例
