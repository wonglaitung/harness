## 技术定义 (What)
用类型化决策（Jev）编排可复用 Agent 流程的 DSL。

## 行业痛点 (Why)
Agent 流程靠 prompt 拼凑，决策隐式、不可复用、难以类型检查。

## 旧范式 vs 新范式
- **旧做法**：prompt + 框架代码硬编码流程
- **新做法**：类型化决策 + DSL 声明式编排
