## 技术定义 (What)
将 207 个 WebGPU 底层 GPU 算子（矩阵乘、归一化、卷积、Attention 原语、量化操作等）以独立版本化 npm 包形式发布到 Hugging Face Hub。每个算子包含 manifest.json（操作契约）、WGSL 着色器模板、正确性测试和性能 benchmark。

## 行业痛点 (Why)
WebGPU 虽提供跨浏览器 GPU 可移植性，但**可移植 ≠ 高性能**。同一算子的不同着色器实现在不同 GPU/浏览器上性能差异巨大。此前框架内嵌算子实现，难以独立优化、测试和版本化。

## 旧范式 vs 新范式
- **旧做法**：算子内嵌在推理框架中，框架各自实现 WebGPU 算子，无法复用，升级需等框架发版
- **新做法**：算子即包（Kernel-as-a-Package），独立版本化、独立测试、独立优化，框架通过加载器按需拉取

## 生产力影响 (How)
- 框架开发者无需重复"造轮子"，直接引用社区验证的最优算子
- 配合 Fleet 众包测试，用户设备上的性能问题可精确定位到具体算子版本
- 形成"发布→测试→优化→版本升级"的独立反馈循环

## 采用成本
- npm install @huggingface/kernels@preview
- 需要 WebGPU 支持的浏览器
- Apache-2.0 许可证，207 个算子初始覆盖

## 风险/局限
- 生态尚在初期，算子覆盖范围和社区贡献活跃度待验证
- 依赖 WebGPU 标准演进和浏览器实现质量
