# OpenMontage

## 技术定义 (What)
首个开源的 Agentic 视频生产系统，将 AI 编程助手转变为完整的视频制作工作室。通过自然语言描述，Agent 自主完成研究、脚本撰写、资源生成、剪辑和最终合成，支持真实视频制作（非简单的图像动画）。

## 行业痛点 (Why)
传统视频制作需要专业技能、多工具协作、高成本；现有 AI 视频工具多为单点功能（仅生成片段或图像动画），缺乏端到端的自动化流程。

## 旧范式 vs 新范式
- **旧做法**：人工使用 Premiere/Final Cut Pro 等工具，需学习剪辑技能、手动收集素材、逐帧编辑，制作一条 60 秒视频需数小时到数天。
- **新做法**：用自然语言描述需求，Agent 自动完成：研究主题 → 生成脚本 → AI 生成图像/视频素材 → TTS 配音 → 自动配乐 → 字幕合成 → 最终渲染，成本降至 $0.15-$1.33/视频。

## 生产力影响 (How)
开发者无需学习视频制作技能，只需一个 AI 编程助手（Claude Code/Cursor/Codex）即可完成专业级视频内容创作，12 条流水线、52 个工具、500+ Agent 技能，极大降低视频创作门槛。

## 采用成本
低门槛：仅需 Python 3.10+、Node.js 18+、FFmpeg，支持多 API 提供商（可选）。学习曲线平缓，README 提供 Agent 操作指南，适合开发者快速上手。
