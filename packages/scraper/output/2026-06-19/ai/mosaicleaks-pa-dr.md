# MosaicLeaks / PA-DR

## 技术定义 (What)
MosaicLeaks 是评估 Deep Research Agent 隐私泄露风险的基准测试，包含 1,001 个多跳研究链（交织本地和 Web 信息）。PA-DR（Privacy-Aware Deep Research）是对应的强化训练方法，在提升任务性能的同时降低隐私泄露，通过情境奖励和隐私奖励联合优化。

## 行业痛点 (Why)
Deep Research Agent 在处理私有文档时，会通过 Web 查询泄露敏感信息。单个查询看似无害，但累积查询日志可被对手重构出私有事实（镶嵌效应）。单纯在提示中要求"不要泄露"效果有限，且损害任务性能。

## 旧范式 vs 新范式
- **旧做法**：在提示中添加隐私约束，但效果不一致且损害任务完成率。或只优化任务性能，但泄露率随之上升（Qwen3-4B 从 34.0% 升至 51.7%）。缺乏系统性方法平衡隐私与效用。
- **新做法**：量化三种泄露类型：意图泄露（预测研究问题）、答案泄露（回答给定私有问题）、全信息泄露（主动发现私有事实）。PA-DR 联合优化情境任务奖励和隐私奖励，在保持严格链成功率的同时将泄露率从 34.0% 降至 9.9%。首次系统解决 Agent 查询隐私问题。

## 生产力影响 (How)
提供量化评估 Agent 隐私风险的基准（1001 条多跳链）。PA-DR 方法将严格链成功率从 48.7% 提升至 58.7%，同时将泄露率从 34.0% 降至 9.9%。为企业部署研究 Agent 提供隐私训练范式。

## 采用成本
研究阶段，需 RL 训练基础设施。基准测试和数据集已公开。PA-DR 方法需集成到训练流程中。适合有 RL 训练能力的团队。论文：https://arxiv.org/abs/2605.30727
