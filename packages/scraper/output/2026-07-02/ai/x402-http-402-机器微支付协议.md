## 技术定义 (What)
x402 Monetization Gateway 是 Cloudflare 推出的基于 x402 开放协议的变现网关，让任何受 Cloudflare 保护的资源（网页、数据集、API、MCP 工具）都可以按请求收费。x402 协议将 HTTP 402 "Payment Required" 状态码从沉睡 30 年的规范变为现实：客户端请求付费资源 → 服务器返回 402 + 价格信息 → 客户端支付并重带支付证明 → 网关验证 → 返回资源。全程在 HTTP 请求内完成，无需跳转支付页面。

## 行业痛点 (Why)
AI Agent 正在成为互联网的主要消费者，但传统 Web 商业模式（广告、订阅）无法服务 Agent：Agent 不看广告，不需要月度订阅，只需单次请求。传统支付通道（Stripe 等）对亚美分交易成本过高、结算太慢，无法支持机器间的微支付场景。

## 旧范式 vs 新范式
- **旧做法**：API Key + 月度订阅 / 按量计费需注册账户 → 人类用户注册、获取 API Key、按月结算；或依赖广告变现内容
- **新做法**：HTTP 请求内嵌支付 → Agent 无需账户，支付本身即凭证，稳定币亚秒级结算，亚美分粒度计费

## 生产力影响 (How)
1. **Agent 开发者**：Agent 可自主完成微支付获取数据/API，无需人工审批每次请求
2. **内容/数据提供者**：零代码实现按请求收费，无需自建支付系统
3. **MCP 工具提供者**：可直接对 MCP 工具调用收费，开启 Agent 工具商业化新路径
4. **开源维护者**：可通过 x402 对 API 访问收费，获得可持续收入

## 采用成本
免费接入（Cloudflare 客户），需配置支付规则和稳定币钱包；非 Cloudflare 用户需自行实现 x402 协议。学习曲线中等，需理解 HTTP 402 协议和稳定币支付流程。

## 采用案例
- **Cloudflare Pay Per Crawl**：AI 爬虫按次付费抓取内容（前序产品）
- **MCP 工具收费**：对 Agent 的 MCP 工具调用按次计费
- **API 端点收费**：$0.01/GET 请求到 /api/premium/*，$0.001 + $0.01/MB 上传
- **按结果收费**：$0.99/已解决的支持升级，仅在成功时支付

## 风险/局限
- 依赖稳定币基础设施，监管不确定性
- 仅支持 Cloudflare 网络内的资源（初期）
- 买方需持有稳定币，增加了 Agent 部署复杂度
- 安全风险：支付验证在边缘节点完成，需防止伪造支付证明
