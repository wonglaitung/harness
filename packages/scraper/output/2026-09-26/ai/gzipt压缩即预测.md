# gzipt（压缩即预测）

## 技术定义 (What)
基于"预测模型即压缩器、压缩算法即预测模型"的等价性，用系统自带的 gzip/zlib（DEFLATE 算法）直接做语言建模：无神经网络、无学习参数、无训练。用语料填充压缩窗口，beam search 搜寻"压缩得最小"的字节续写。

## 行业痛点 (Why)
语言建模几乎被等同于"训练巨型神经网络"，代价高昂。是否存在不依赖权重、不依赖训练的生成路径？压缩-预测等价性揭示：任何压缩器内部都藏着一个概率模型。

## 旧范式 vs 新范式
- **旧做法**：语言建模 = 训练神经网络的权重（从零预训练或微调），需要 GPU 与海量算力。
- **新做法**：用 DEFLATE 压缩窗口 + beam search 直接续写文本，仅靠一个标准库 Python 文件（zlib），零权重、零训练。压缩长度即打分函数，越小越"被预测"。

## 生产力影响 (How)
证明"压缩即预测"可从理论落到可运行的生成工具，为无训练/低资源生成与信息论教学提供新视角；虽输出不够连贯（作者自认），但概念价值重大。

## 采用成本
输出质量远低于神经网络（toy 级演示）；受 32KB DEFLATE 滑动窗口限制；需处理字节级 beam search 的量化噪声。非实用生成工具。
