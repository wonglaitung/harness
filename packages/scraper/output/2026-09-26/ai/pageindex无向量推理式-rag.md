# PageIndex（无向量、推理式 RAG）

## 技术定义 (What)
受 AlphaGo 启发的无向量（vectorless）RAG 引擎：用层次化树索引替代向量索引，让 LLM 像人类专家翻阅报告一样"推理式"检索。索引时生成树结构，检索时用 LLM 在树上推理搜索，无需向量数据库、无需 chunking。

## 行业痛点 (Why)
向量 RAG 按"语义相似度"检索，但"相似 ≠ 相关"——相关需要推理。在金融、法律、医疗等需要上下文理解与多步推理的专业长文档上，相似度检索会漏掉相关但不相似的、并返回相似但不相关的。

## 旧范式 vs 新范式
- **旧做法**：向量索引 + 语义相似度搜索，结果不透明（"vibe retrieval"）、上下文仅靠 query embedding、依赖 chunking。
- **新做法**：树索引 + LLM 推理式搜索，结果可追溯到显式引用、可解释，上下文包含完整对话历史与领域知识；无向量库、无 chunking。

## 生产力影响 (How)
FinanceBench 达 98.7% 准确率（向量 RAG 仅 50%）；索引成本约 $0.001/页，长文档查询成本远低于原生 PDF 输入（420 页时便宜 16.6x）。对专业长文档检索是质变。

## 采用成本
需换用树索引工作流（放弃向量库），索引/查询各需一个 LLM（索引可用基础模型、查询需最强模型）；当前对文本 PDF 效果最佳，复杂图片/OCR 走云端。
