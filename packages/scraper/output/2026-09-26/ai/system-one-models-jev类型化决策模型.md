# System One Models / Jev（类型化决策模型）

## 技术定义 (What)
TypeSafe 提出的"System One 模型"新类别：放弃字符串生成，专为快速结构化决策设计。新架构 + 并行采样器 + 新训练方法 RLCD（校准决策强化学习）。首个模型 Jev：非结构化状态进，类型化概率决策出，数学上不可能产生类型错误或幻觉。

## 行业痛点 (Why)
LLM 已在聊天上超人多年，却没有带来自动化——因为字符串输出灵活但不可靠：需要解析+校验、可能幻觉、速度慢（3-329 秒）、昂贵、置信度不可靠。无法直接嵌入软件做可靠判断。

## 旧范式 vs 新范式
- **旧做法**：LLM 顺序自回归生成 token，输出字符串（可能幻觉/越界），需人工监督或解析校验，每次调用 3 秒到数分钟、成本高。
- **新做法**：并行一次性生成所有输出的概率分布，输出类型安全结构化值，始终附带校准置信度，端到端 70ms-500ms（40x-200x 加速），输出 token 免费（$0.042/MTok 输入）。作为"智能 if 语句"直接嵌入普通代码。

## 生产力影响 (How)
让 AI 决策直接嵌入软件工作流（分类、路由、评分、抽取、分支），实现"验证一切"、地图归约大数据、实时应用——把 AI 从"需人工监督的对话"推向"可靠自动化决策"。

## 采用成本
需学习新 API 与 System One LLM 适配器；目前 early access；仅适用于结构化决策类任务（System One 形态），不替代通用生成。
