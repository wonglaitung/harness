## 技术定义 (What)
System One Model 是抛弃字符串生成的新型模型：输入非结构化状态，输出预先定义的、类型安全的结构化值（choice/score/yes-no），每项答案附带校准概率与置信度。采用并行采样（单次前向传播）替代逐 token 生成，用 RLCD 训练。

## 行业痛点 (Why)
LLM 在自动化中失败的三根源：延迟（3-329秒）、解析/幻觉风险、置信度不可靠。当模型能做 95% 任务却不知何时落入 5% 失败区间，就无法真正自动化。

## 旧范式 vs 新范式
- **旧做法**：LLM 生成字符串 → JSON 解析 → 校验 → 有幻觉/类型错误风险，逐 token 慢且贵
- **新做法**：Jev 直接并行输出结构化值 + 校准概率，数学上不可能类型错误，70-500ms，输出免费

## 生产力影响 (How)
把 AI 变成可信的"智能 if 语句"，可安全嵌入普通软件代码做分类/路由/打分/分支，支撑 PB 级数据 map-reduce 与实时应用，还能低成本 guardrail 其他 LLM。

## 采用成本
极低：SDK 接入，输入 $42/十亿 token、输出免费；本地可用 Ollaya 跑开源决策模型（如 decider、laya）。

## 采用案例
- **Ollaya**：本地运行 Jev 风格决策模型的 Ollama 类工具，兼容 TypeSafe API
- **JevBench**：类型化决策模型的可复现基准
- **Jev Plays Pokémon Red**：用决策模型玩游戏的交互 demo

## 风险/局限
- 放弃字符串生成 = 无法做聊天/代码生成，仅限决策型窄任务
- 定价可持续性待长期验证（作者自承可能被补贴）
- 创始人承认 workflow evals 存在团队自建数据的潜在偏差
