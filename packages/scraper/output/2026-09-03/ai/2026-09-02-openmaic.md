## 技术定义 (What)

OpenMAIC（Open Multi-Agent Interactive Classroom）是清华 MAIC 团队开发的**多 Agent 互动课堂**。一句话生成完整课程：一个 Agent 负责课程大纲规划，多个 Agent 协同构建课堂内容（幻灯片、测验、互动组件、视频、语音），学生在多 Agent 环境中进行沉浸式学习。核心突破是将"AI 辅助教学"升级为"Agent 原生教学"——Agent 不是工具，而是教学的**组织者**。

## 行业痛点 (Why)

传统在线教育是"录播视频 + 选择题"的静态模式。即使有 AI 辅助，也只是在内容生成端（自动出题、自动总结），学生端的互动体验没有根本改变。真正的痛点是：**一人一套内容，无法动态适应不同学生**。

## 旧范式 vs 新范式

- **旧做法**：教师录制课程 → 学生被动观看 → AI 辅助生成练习题（AI 是辅助工具）
- **新做法**：Agent 规划课程大纲 → 多 Agent 协同构建互动课堂 → 学生在 Agent 环境中沉浸式学习（Agent 是教学组织者）

## 生产力影响 (How)

1. **一键生成全课程**：输入一个 prompt，生成包含幻灯片、测验、互动、PBL 项目、视频、语音的完整课程
2. **Agent 工作台**（v1.0）：对话式课程构建，Agent 规划、构建、修改每个页面
3. **会话材料**：上传文档/音频/视频，Agent 从中构建课程内容
4. **模型中立**：支持任意 LLM、媒体、搜索、存储后端
5. **20+ 内置技能**：幻灯片、测验、互动、PBL、图片、视频、语音、PPTX 导入

## 采用成本

- **时间**：Vercel 一键部署，1 分钟内上线
- **金钱**：开源免费（MIT），只需 API 调用费
- **学习曲线**：低，prompt 即课程

## 采用案例

- **在线 Demo**：https://open.maic.chat/ 已上线
- **学术支撑**：JCST'26 论文（Journal of Computer Science and Technology）

## 风险/局限

- 课程质量依赖底层 LLM 能力，需要强模型驱动
- 当前主要面向知识传递型教育，实操/实验型场景覆盖有限
- 多 Agent 协作可能引入一致性问题
