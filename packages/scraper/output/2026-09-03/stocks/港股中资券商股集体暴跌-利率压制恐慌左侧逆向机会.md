## 市场信号解读

### 为什么券商暴跌？

```
美债4.80% → 无风险利率攀升 → 券商双重承压：
├─ 自营盘：债券持仓浮亏扩大
├─ 经纪业务：市场低迷，交易量萎缩
├─ 投行业务：IPO虽然热度高，但利率环境不利
└─ 估值层面：DCF分母增大，高Beta标的首当其冲
```

### 为什么是左侧逆向机会？

**中金公司(03908.HK)为例**：
- 单日跌6.94%报20.92港元，为近期最大单日跌幅
- 中金作为投行龙头，直接受益于港股IPO扩容（中际旭创550亿、Momenta等）
- 港股IPO市场热度处于历史高位：基石投资962笔同比+269%
- 港交所GEM合并+18D章初创通道改革：中金作为头部保荐人最受益

**核心逻辑链**：
```
港股IPO扩容（确定性趋势）
  → 中金保荐承销收入增长（确定性受益）
  → 利率压制导致股价暴跌（短期情绪）
  → 估值修复至合理区间（左侧机会）
```

- **中金表现**：从低点反弹+25%（3个月内）
- **反弹逻辑**：政策托底+投行业务恢复
