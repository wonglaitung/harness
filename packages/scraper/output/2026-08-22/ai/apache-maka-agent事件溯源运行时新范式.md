## 技术定义 (What)

Maka 是一个 **本地优先的 Agent 工作空间**。核心理念：所有模型消息、工具调用、工具结果、权限决策作为**追加事件日志（append-only log）**记录。Session、UI、上下文和恢复都是该日志的"投影（projections）"。这类似事件溯源在 Agent 领域的首次系统化应用。

## 行业痛点 (Why)

当前所有 Agent 工具的上下文管理混乱：
- 聊天历史、工具调用、权限记录混在一起，难以调试
- Agent "失忆"后无法恢复状态
- 无法审计 Agent 每步决策

## 旧范式 vs 新范式

- **旧做法**：Agent 会话 = 聊天线程，历史是上下文，坏了就重来
- **新做法**：Agent 会话 = 事件日志投影。工具输出裁剪≠丢弃证据。每个 Turn 可分支、恢复、审计

## 生产力影响 (How)

- **可恢复性**：Agent 崩溃后可从日志重建到崩溃前状态
- **可审计性**：每条工具调用都有轨迹，安全审计可行
- **可分支**：从任一个 Turn 分叉探索不同方案

## 采用成本

- 设计理念需要学习成本（事件溯源思维）
- macOS 桌面版开箱即用，零配置
- 开源 Apache 2.0 许可，无厂商锁定

## 采用案例

- **Apache 基金会**：作为官方孵化项目，有社区治理背书
- **本地优先 Agent 场景**：隐私敏感、需离线工作的开发者

## 风险/局限

- 早期阶段，Windows/Linux 尚未正式支持
- 数据格式和 CLI 命令仍可能变化
- 事件溯源范式对多数开发者是全新的
