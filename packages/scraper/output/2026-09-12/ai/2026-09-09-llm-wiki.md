## 核心创新

1. **编译式而非检索式**：RAG 每次从零重建答案；LLM Wiki 将知识编译为持久化页面
2. **两步 Chain-of-Thought Ingest**：Step 1 分析（关键实体/概念/关联），Step 2 生成 Wiki 页面——显著提高质量
3. **SHA256 增量缓存**：源文件内容哈希 → 未变化文件自动跳过，节省 token
4. **4-Signal 知识图谱 + Louvain 社区发现**：自动发现知识簇和意外关联
5. **Deep Research**：LLM 优化搜索主题 → 自动检索 → 结果摄入 Wiki
6. **Agent Skills 集成**：可作为编码 Agent 的知识引擎
7. **MCP Server + HTTP API**：任何 Agent 可通过 MCP 协议查询 Wiki

## 技术栈

Rust 后端 + React 前端（Tauri 桌面应用），SQLite + LanceDB（向量搜索）

## 首发时间

基于 Karpathy 的 [llm-wiki.md](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) 理念，Nash Su 实现为桌面应用。GitHub 趋势 640 stars/day（2026-09-12 当日）。

## 风险/局限

- 依赖 LLM 的提取质量，复杂文档可能产生不准确的 Wiki 页
- 大型文档库的初次导入可能消耗大量 token
- 需要手动校正 LLM 生成的内容
