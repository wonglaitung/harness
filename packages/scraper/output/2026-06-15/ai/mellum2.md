# Mellum2

## 技术定义 (What)
JetBrains 推出的 12B 参数 MoE（Mixture-of-Experts）模型，专为低延迟文本和代码工作负载优化。每 token 仅激活 2.5B 参数，实现 2 倍以上的推理加速。Apache 2.0 开源许可，支持私有化部署。

## 行业痛点 (Why)
现代 AI 系统依赖多模型协作：路由、检索、摘要、规划、验证、工具调用。许多操作对延迟敏感，但不需要最大的前沿模型。使用单一巨型模型处理所有任务，既昂贵又低效。企业需要轻量级、高吞吐量的模型处理高频次、低复杂度的任务。

## 旧范式 vs 新范式
- **旧做法**：在多模型系统中，所有任务（包括简单路由、摘要、格式转换）都使用大模型（如 GPT-4、Claude），导致高成本、高延迟。或者在系统架构中引入非 AI 规则引擎，牺牲灵活性换取性能。
- **新做法**：引入"焦点模型"（Focal Model）概念：在多模型系统中部署轻量级 MoE 模型，专门处理高频、低延迟任务（路由决策、RAG 后处理、子代理任务），将大模型保留给真正需要推理能力的环节。MoE 架构保持总容量高（12B），但激活参数少（2.5B），兼顾能力与速度。

## 生产力影响 (How)
将多模型系统的平均响应延迟降低 50-70%，API 调用成本降低 60-80%。特别适合 IDE 内置 AI、RAG 管道、Agent 子任务场景。支持私有化部署，满足企业对代码安全和数据隐私的要求。作为路由模型，可动态选择是否需要调用大模型，优化系统整体成本结构。

## 采用成本
低。Hugging Face 可直接下载，兼容 OpenAI API 格式。12B 总参数量在单张消费级 GPU（如 RTX 4090）即可运行。JetBrains 提供 Docker 镜像和示例代码。对已有 AI 系统架构改动小，只需在路由层引入 Mellum2 作为前置模型。
