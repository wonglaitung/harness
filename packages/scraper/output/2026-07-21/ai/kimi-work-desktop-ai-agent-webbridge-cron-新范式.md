## 技术定义 (What)
Kimi Work是Moonshot AI推出的桌面AI Agent：它不是聊天助手，而是系统级数字员工。核心三大能力：(1) 本地文件系统深度挂载，Agent可直接读写本地文件；(2) WebBridge自主浏览器，Agent像人一样点击、滚动、提取网页数据；(3) 内置Cron引擎，支持24/7定时执行LLM Agent调用、Python脚本、Shell命令。此外还支持Agent Swarm多智能体协作，以及原生金融数据集成（A股、港股、美股）。

## 行业痛点 (Why)
当前AI Agent产品存在三大断裂：(1) 聊天Agent无法触及本地文件，知识工作者的核心资产在本地；(2) 浏览器自动化需要手动配置，无法自主导航；(3) Agent只能按需触发，无法定时自主运行。知识工作者的重复性任务（每日简报、数据抓取、报告生成）仍需人工启动。

## 旧范式 vs 新范式
- **旧做法**：AI聊天助手 → 手动复制粘贴 → 手动打开浏览器 → 手动设置定时脚本。Agent是被动响应工具，用户是调度中心。
- **新做法**：桌面AI Agent → 自主挂载本地文件 → WebBridge自主浏览 → Cron引擎24/7自动执行。Agent是主动执行者，用户是目标设定者。

## 生产力影响 (How)
- 知识工作者可将重复性日常任务（每日简报、市场数据抓取、报告生成）完全自动化
- WebBridge让Agent自主完成多步骤网页操作，省去手动浏览和提取数据的时间
- Agent Swarm可并行处理复杂研究任务，自动生成PPT/Excel
- 金融从业者可直接用自然语言查询全球市场数据，无需API配置

## 采用成本
- 免费使用（Kimi Work桌面应用）
- 学习曲线低：自然语言交互，无需编程
- 需要安装桌面客户端（macOS/Windows）
- 本地文件访问需用户授权确认（安全机制）

## 采用案例
- 金融分析：自然语言查询A股/港股/美股数据，自动生成分析报告
- 研究工作：Agent Swarm并行搜索，自动汇总为PPT
- 日常自动化：Cron定时每日生成工作简报、处理数据集

## 风险/局限
- 本地文件修改需用户确认，高频操作可能产生确认疲劳
- WebBridge自主浏览可能触发网站反爬机制
- Agent Swarm多智能体协调的可靠性尚待验证
- 目前仅支持Kimi自有模型，模型能力上限决定Agent能力上限
