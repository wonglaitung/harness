## 双面信号解读

### 🔴 风险面：高估值次新股面临重新定价

**核心逻辑**：
1. **基石投资者获利了结冲动**：兆易创新H股+377%，早期财务投资人浮盈巨大，"抢跑卖出"预期先于实际减持打压股价
2. **AI概念估值泡沫**：智谱/MINIMAX上市时享受AI龙头溢价，解禁后估值可能回归基本面
3. **供给冲击**：千亿级解禁规模远超日常成交，流动性难以承接
4. **半年报验证期**：解禁+半年报双重压力，靠赛道与概念撑起的高估值可能被证伪

**传导路径**：
```
解禁日临近 → 早期投资者抢跑卖出 → 股价承压 → 散户恐慌跟卖 → 超跌
→ 基本面未变的优质标的被错杀 → 逆向布局机会
```

### ✅ 机会面：恐慌出逃后的逆向布局

**核心逻辑**：
1. **解禁≠减持**：限售股解禁只是获得流通权，不代表立即卖出。基石投资者若看好长期价值可能继续持有
2. **恐慌出逃创造买点**：智谱/MINIMAX单日跌10%+，若基本面未变则属于情绪性超跌
3. **南向资金19.58%创新高**：内地资金可能趁解禁恐慌低吸优质标的
4. **AI产业趋势未变**：大模型/AI应用长期趋势不变，短期解禁冲击不改变产业方向

**逆向布局条件**：
- ✅ 基本面未恶化（营收/用户持续增长）
- ✅ 解禁冲击已充分反映（跌幅>15%）
- ✅ 南向资金开始逆势加仓
- ❌ 估值仍远高于行业平均（PE > 50x）→ 不宜逆向
