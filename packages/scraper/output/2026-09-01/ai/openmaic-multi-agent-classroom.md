## 技术定义 (What)

OpenMAIC (Open Multi-Agent Interactive Classroom) 是清华大学 MAIC 实验室开源的**多Agent互动课堂系统**。用户输入一个主题，多个 AI Agent 协同工作：课程规划 Agent 设计教学大纲，内容生成 Agent 编写课程页面，媒体 Agent 生成图片/视频/配音，测验 Agent 创建互动练习。所有内容可一键导出为完整课程包。

核心架构：LangGraph 多Agent编排 + Next.js 前端 + 模型无关设计（支持 OpenAI/Claude/Gemini/DeepSeek/GLM/Kimi 等）。

## 行业痛点 (Why)

传统在线教育内容制作需要：课程设计师 → 内容作者 → 美工 → 视频制作 → 配音 → 测试设计，6 个角色数周工作。OpenMAIC 将整条流水线压缩为**一句话提示 + 几分钟等待**。

## 旧范式 vs 新范式
- **旧做法**：人工课程设计（数周）+ 单Agent辅助（ChatGPT回答问题）
- **新做法**：一句话描述需求 → 多Agent自动协同 → 完整互动课程自动生成

## 生产力影响 (How)

- 课程制作时间从数周 → 数分钟
- 支持 PBL（项目式学习）、3D可视化、互动编程、游戏化学习
- 模型无关设计，可接入本地模型（Ollama）+ Lemonade 本地AI栈
- 学术发表：JCST 2026 论文支持

## 采用成本

- 免费开源（MIT）
- 一键 Vercel 部署
- 模型成本：依赖用户自己的 API Key
- 学习曲线：低（自然语言操作）

## 采用案例

- **清华大学**：内部课程制作
- **开放 Demo**：open.maic.chat 可即时体验
- **Lemonade 本地AI**：无需云服务即可运行

## 风险/局限

- 课程质量依赖底层模型能力
- 复杂专业课程可能需要人工审核
- 多Agent协作的Token消耗较高
- 生态仍在早期
