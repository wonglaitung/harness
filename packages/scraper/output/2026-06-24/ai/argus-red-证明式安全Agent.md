## 技术定义 (What)

Argus Red 是一个 AI 安全 Agent CLI 工具，核心创新在于"证明式安全审计"：它不仅发现代码中的漏洞，还能在隔离环境中实际复现漏洞（Exploit Verification），让安全报告从"理论推测"变为"已验证事实"。提供两种模式：Security Scan（读代码+推理）和 Pen Test（对授权目标发起真实攻击）。

## 行业痛点 (Why)

传统安全扫描工具（SAST/DAST）只报告"可能的漏洞"，误报率极高，安全团队需要大量时间逐一验证。渗透测试则需要专业安全人员手动操作，成本高、周期长。AI Agent 在安全领域的应用一直受限：要么太保守（拒绝提供安全信息），要么太激进（无法控制攻击范围）。

## 旧范式 vs 新范式

- **旧做法**：SAST工具报告潜在漏洞 → 安全工程师手动验证 → 渗透测试师手动攻击验证
- **新做法**：AI Agent 自动发现漏洞 → 在 Docker/沙箱中自动复现 → 输出已验证的漏洞报告

## 生产力影响 (How)

- 安全审计效率提升：30K LOC 项目约10分钟完成扫描
- 漏洞验证自动化：从"发现→人工验证"缩短为"发现→自动复现"
- 渗透测试民主化：非安全专家也能运行基本渗透测试

## 采用成本

- 免费安装（brew install），2M免费token
- 渗透测试模式需预约授权（合规要求）
- 学习曲线低：CLI工具，交互式TUI

## 采用案例

- Bank of Anthos（~30K LOC）：6模块扫描，10分钟完成，发现多个关键漏洞
- Symfony（~1.5M LOC）：完整扫描40分钟

## 风险/局限

- 渗透测试模式的法律风险需自行承担（工具要求书面授权）
- 漏洞复现可能在生产环境造成意外影响
- 依赖 Cosine 平台的 token 计费
- 新项目，社区验证不足
