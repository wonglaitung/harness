## 技术定义 (What)
为每个具体任务训练超小专用模型（2-284MB），运行在设备本地（Neural Engine/GPU），通过统一 SDK（Swift/Kotlin/JS）以几行代码集成。首发18个模型：Voz（转录，4.7x Whisper）、Clear（9MB 降噪，302x 实时）、Redact（12MB PII 脱敏，达 2.3GB 模型 97.5% 准确率）、Clips（284MB 视频剪辑，替代 Claude Sonnet）。

## 行业痛点 (Why)
全球每年出货 10 亿+ 设备内置强大芯片，但 AI 能力仍以云 API 为主。NVIDIA 研究发现 Agent 40-70% 的大模型调用可用小型专用模型替代。这些任务不需要"通用智能"，只需要又快又准地完成一件事。

## 旧范式 vs 新范式
- **旧做法**：音频转录 → 上传到 Whisper API → 等待 → 付费。PII 检测 → 数据离开设备 → 隐私风险。
- **新做法**：Voz 2 秒转录 10 分钟音频在 iPhone 上完成。Redact 在数据离开设备前拦截 PII。Clips 在本地完成视频剪辑，10x 更快，能耗仅为 Sonnet 的 1/470。

## 生产力影响 (How)
- 推理零成本 → 每个交互都能用 AI，不再"选择性"调用
- 零延迟 → 逐帧/逐键实时处理成为可能
- 数据不出设备 → GDPR/隐私合规默认满足
- 一套 SDK 三平台 → 跨 iOS/Android/Web 统一体验

## 采用成本
- **学习成本**：极低（几行代码，类 REST API 风格）
- **金钱成本**：100k MAU 免费，无需服务器
- **适用边界**：结构化任务（转录/分类/脱敏/增强），不适合开放式推理

- 端侧芯片碎片化（不同 iPhone/Android 代际差异）
- 欧洲公司，中国市场 SDK 可用性未知
- 生态初期，第三方模型/插件体系未建立
