# Self-Convened Verification Cohort（自组验证小队：模型复制体自成研究组并交叉验算）

## 技术定义 (What)
让同一个模型开多个副本组成"小型研究组"并行推进一个数学/物理推导：每个副本独立算出计算的绝大部分，再各自用已知结果做自检，最后由主会话对交叉一致性收敛。产物是两篇解决公开未解问题的预印本，而非聊天记录。

## 行业痛点 (Why)
长链条理论推导（如 2003 年提出、20 余年未完成的相变计算）单条上下文根本推不完：中间步骤一旦出错，后续全错且无法察觉。此前的做法是人类分组手算 + 互相 review，周期以年计。

## 旧范式 vs 新范式
- **旧做法**：长推理 = 单条极长思维链，靠"想得更久"提升正确率；验证 = 事后再跑一遍或人工检查。验证与生成在同一个上下文里，错误会自我强化。
- **新做法**：把「并行副本 + 独立重算 + 已知结果锚定」作为推导的默认结构：冗余不是浪费，而是可验证性的来源。判定标准从"答案看起来对"变成"多个独立副本是否收敛到同一结果，且各自与已知极限一致"。这同时给出了一种可操作的 RSI 证据形式——模型不仅产出结论，还自组织出验证结论的社会结构。

## 生产力影响 (How)
对科研与工程推导（形式化证明、物理建模、复杂数值推导）提供可复制的工作模式：把昂贵的长链任务改为 N 路独立求解 + 交叉裁决，正确率可用"收敛率"作为在线信号，而非等到最后才发现崩盘。也是评估"研究级 Agent"能力的新任务形态。

## 采用成本
高（算力与设计）：N 倍 token 成本；需设计"独立"边界（副本之间不能共享中间稿，否则失去冗余价值）；需准备锚定用的已知结果集。当前仅由具备前沿模型访问权的团队实操验证。
